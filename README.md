<h1 align="left">☕ Starcoffee</h1>

###

<p align="left">Одностраничный сайт, созданный для демонстрации кофейного бренда. Проект оформлен в тёплой, уютной стилистике и включает ключевые блоки: меню, преимущества, отзывы и контактную информацию.</p>

###

<h2 align="left">📦 Стек технологий</h2>

###

• Vite — мгновенная сборка и dev-сервер

• HTML5 + CSS3 — адаптивная и семантическая верстка

• JavaScript — интерактивные элементы

• Swiper библиотека для JS

• GitHub Pages — хостинг лендинга

###

<h2 align="left">📁 Структура проекта</h2>

###

```
starcoffee/
```
